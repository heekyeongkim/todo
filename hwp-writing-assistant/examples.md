# 변환 예시 (기사·보도자료 → 행정문서)

문체는 **개조식 명사형, 마침표 없음**이다. 규칙은 `SKILL.md`에 있고, 여기는 적용 예시다.

## 1. 어미 정리

| 전 | 후 |
|---|---|
| `…퍼부었습니다` | `…의혹 8가지를 열거` |
| `예산 확보 시급` (단어 나열) | `사업 추진에 필요한 예산의 조기 확보가 시급` |
| `관계기관 협의 완료` | `관계기관 협의를 '26.2월 완료` |
| `교육을 실시할 예정입니다` | `전 직원 대상 교육 실시 예정` |

서술어를 살리되 명사형으로 맺고 마침표를 찍지 않는다.

## 2. 라벨 프리픽스로 묶기

기사는 원인·배경·수치가 여러 문단에 흩어져 있다. 같은 갈래끼리 묶고 라벨을 붙인다.

**(전)** 편중된 시장 구조 때문이라는 분석입니다. … 변동성이 극심합니다. … 레버리지 손실이
커졌습니다. *(세 문단에 흩어짐)*

**(후)**
```
2. 이탈 원인
○ (시장 구조) 반도체 상위 2개 종목에 편중된 구조로 지수 전체가 두 종목 주가에 따라 급등락
○ (변동성) 코스피가 단기간에 폭락과 폭등을 반복하며 하루에도 방향성이 수차례 전환
○ (레버리지 손실) 단일종목 레버리지 상품 도입으로 변동성과 손실폭이 확대
```

## 3. 기사체 용어 정리

| 기사 | 문서 |
|---|---|
| 개미 | 개인투자자 |
| 투톱 | 상위 2개 종목 |
| 국장 | 국내 증시 |
| 저격, 포화, 직격 | 비판, 지적 |

직접 인용은 '따옴표'로 그대로 보존한다 — `'음의 복리 효과'가 겹치며`

## 4. 근거·출처는 ※ 로 분리

```
○ (개인) '26.7월 코스피 개인투자자 거래대금 비중은 31.23%로, 1월 48.19% 대비 16.96%포인트 감소
※ 단위: %, 자료: 한국거래소('26.8.4. 발표)
```

## 5. 없는 내용은 만들지 않는다

기사에 분야만 있고 세부 항목이 없으면 지어내지 말고 남긴다.

```
○ (질의 분야) 부동산·금융·사법 정책 등 주요 국정 현안
- 8가지 항목의 개별 내용은 보도에 적시되지 않아 확인 필요
```

## 6. 일정·체계는 표 대신 서술식

**(전)** 표: `14:00~14:30 | 30분 | 사례 발표 | 삼성SDS`

**(후)**
```
○ 교육은 다음 순서로 진행
- 14:00부터 30분간 삼성SDS가 AI 친화적 문서혁신 사례를 발표
- 14:30부터 25분간 혁신행정담당관실이 문서 작성 방법을 설명
```

## 7. 금지문자 치환

**(전)** `▲ 예산 확보 ▲ 인력 충원 ▲ 제도 개선` — 언론 기사체
**(후)** `① 예산 확보, ② 인력 충원, ③ 제도 개선`

`▲ ◆ ■ ● ▶ ▷ ☞` 는 공문서에 쓰지 않는다. 기존 문서의 `▲`는 후처리가 자동 치환한다.
