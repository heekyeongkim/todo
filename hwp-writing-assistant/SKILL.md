# 한글 행정문서 작성 지원

행안부 「AI 시대 행정문서 작성 가이드라인」을 바탕으로 실제 부처 계획서의 서식·문체를
반영한 **하나의 서식**으로 문서를 만든다. 서식 선택지는 없다.

## 실행

```
python make.py 원고.md          # 검증 → 생성 → 후처리 → 실측 내어쓰기 → 미리보기
```

`--out 파일.hwpx` `--force`(숫자 오류 무시) `--open` `--no-shift-tab`.
`make.ps1`도 동일(`-Out` `-Force` `-Open` `-NoShiftTab`).

**숫자 오류(❌)가 있으면 hwpx를 만들지 않고 멈춘다.** 고친 뒤 다시 돌린다.
스크립트가 출력하는 리포트(검증 결과, 자간·장평 조정/불가 줄 수)는 **그대로 사용자에게 전달**한다.

단계별로 돌려야 하면: `scripts/` 의 `check_numbers.py` → `build_hwpx.py` → `hwpx_polish.py`
→ `hwpx_shifttab.py` → `preview_hwpx.py` 순서다. **후처리(`hwpx_polish.py`)를 건너뛰면
한글에서 글자가 겹친다.**

## 문체 — 개조식 명사형, 마침표 없음

| 쓰지 않음 | 씀 |
|---|---|
| `…방안을 마련함.` | `…방안을 마련` |
| `…배포하였습니다.` | `…조사표 마련·배포` |
| `…확인할 필요가 있음.` | `…사전 확인` |

- **라벨 프리픽스를 기본으로 쓴다**: `○ (방법) …`, `○ (대상) …`, `○ (기간) …`, `○ (참여도) …`
- 날짜는 `'26.6.26. ~ 7.12.` 형식.
- 강조는 볼드가 아니라 「」(정책·문서명), '따옴표'(개념·인용).
- 기사체를 정리한다: `개미`→`개인투자자`, `투톱`→`상위 2개 종목`. 직접 인용은 따옴표로 보존.
- **금지**: `▲ ◆ ■ ● ▶ ▷ ☞` (기존 문서의 `▲`는 후처리가 `①②③`으로 자동 치환)

## 입력 마크업

| 줄 시작 | 의미 |
|---|---|
| `# 제목` | 문서 제목 — **한 줄**, 표·박스 금지. 계획서는 `…계획(안)` |
| `## 요약` | 번호 없는 절 제목 — **첫 절은 반드시 `## 요약`** |
| `> 문장` | 요약 본문 — **기호 없이, 두 줄 이내** |
| `1.` / `가.` | 번호 절 제목(굵게) — 요약 다음부터 |
| `□` | 대항목 — **`1.` 과 동급** |
| `○` | 중항목 |
| `- ` | 세부항목 |
| `·` | 세부항목 |
| `※ ` | 근거·출처 |
| `* ` | 각주 (본문 끝에 `*` 를 달고 다음 줄에서 받음) |
| `[참고1] …` | 별지 제목 — 새 쪽에서 시작 |
| `\| a \| b \|` | 표 (연속된 줄이 하나의 표, `\| --- \|` 있으면 첫 행이 머리행) |

한 줄이 곧 한 문단이다. **줄 앞에 공백을 넣어 계층을 흉내내지 않는다** — 계층은 후처리가
문단 왼쪽 여백(`left`)으로 넣는다.

### 계층 시작점 (기호마다 고정)

같은 기호는 문서 어디에 있든 항상 같은 지점에서 시작한다. 한 수준 = 글자크기의 반 칸.

| 수준 | 기호 | 시작점(15pt) |
|---|---|---|
| 0 | `1.` `2.` `3.` = `□` | 0 |
| 1 | `○` | 750 |
| 2 | `-` | 1500 |
| 3 | `·` | 2250 |
| — | `※` `*` | 바로 위 항목보다 한 칸 안쪽 |

### 표

- **셀 병합·표 안의 표·대각선 금지.** 병합이 필요해 보이면 같은 값을 반복해 채운다.
- 조직도·체계도·일정표는 표로 만들지 말고 **서술식으로 풀어 쓴다**.
- 열 너비·정렬·머리행 음영은 자동 처리된다. 표 안 합계는 자동 검산된다.

## 반드시 지킬 것

1. **없는 내용을 만들지 않는다.** 원문에 없으면 `- … 확인 필요`로 남기고, 시사점·대응방안도
   근거가 없으면 넣지 않는다. 무엇을 뺐는지 사용자에게 말한다.
2. **숫자·고유명사·날짜는 원문 그대로 옮긴다.** 자동 검증은 문서 **내부의 산술·형식 정합성만**
   본다. 출처와 맞는지는 사람이 대조해야 하므로 이 한계를 함께 알린다.
3. 원문에 날짜가 `12일` 처럼만 있으면 연·월을 보완하되 **가정한 사실을 밝힌다.**
4. 결과를 전달할 때 한글에서 확인할 것을 안내한다 — ① 줄바꿈이 어절 경계인가
   ② 이어지는 줄이 기호 뒤 본문 시작 위치에 정렬됐는가 ③ 글자 겹침이 없는가 ④ 표 테두리·열 너비.
   "조정 불가"로 보고된 줄은 한글에서 그 줄만 블록 잡아 장평 90~98%·자간 -3~-9로 손본다.

## 결과 확인

```
python scripts/preview_hwpx.py 결과.hwpx --detail
```

`[좌여백 750, 내어쓰기 -2306, 자간 -4~0]` 처럼 표시된다. **좌여백이 없으면 계층 들여쓰기가
안 걸린 것**이다. 다만 미리보기는 근사치이고 줄바꿈·글꼴은 한글에서만 정확하다.

## 참고 파일 (필요할 때만 연다)

- `examples.md` — 기사·보도자료 → 행정문서 변환 예시
- `sample.md` — 입력 마크업 예시 원고
- `item-numbering.md` — 번호항목 순서·유니코드 표
- `layout-rules.md` — 후처리가 하는 일의 원리 (문제 진단·스크립트 수정 시)
- `template-field.hwpx` — 기준 템플릿. **서식이 지정된 문서(국외훈련 계획서 등)는
  그 서식을 우선**하며 표 구조를 유지한 채 내용만 채운다.
