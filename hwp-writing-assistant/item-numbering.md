# 항목 기호 순서 및 유니코드 표

## 번호항목 사용 순서 (위계 순)

| 단계 | 기호 | 예 |
|---|---|---|
| 1단계 | `Ⅰ.` `Ⅱ.` `Ⅲ.` | 대분류 |
| 2단계 | `1.` `2.` `3.` | 장 |
| 3단계 | `가.` `나.` `다.` | 절 |
| 4단계 | `1)` `2)` `3)` | |
| 5단계 | `가)` `나)` `다)` | |
| 6단계 | `(1)` `(2)` `(3)` | |
| 7단계 | `(가)` `(나)` `(다)` | |
| 8단계 | `①` `②` `③` | |
| 9단계 | `㉮` `㉯` `㉰` | |

## 특수기호 사용 순서 (위계 순)

| 수준 | 기호 | 유니코드 |
|---|---|---|
| 0 | `□` — **`1.` 과 동급** | U+25A1 (WHITE SQUARE) |
| 1 | `○` | U+25CB (WHITE CIRCLE) |
| 2 | `-` | U+002D (HYPHEN-MINUS) |
| 3 | `·` | U+00B7 (MIDDLE DOT) |
| — | `※` U+203B, `*` U+002A — 바로 위 항목보다 한 칸 안쪽 | |

수준별 시작점(좌여백)은 `SKILL.md`의 「계층 시작점」 표를 따른다.

## 주의

- 특수기호는 **반드시 유니코드 문자**를 사용한다. 한글 프로그램의 '문단 번호/글머리표'
  자동기능이나 이미지 기호가 아니라, 문자표에서 입력한 실제 문자여야 AI가 인식한다.
- 로마숫자 `Ⅰ`(U+2160), 원숫자 `①`(U+2460), 괄호원 `㉮`(U+327E 계열)도 유니코드 문자를 쓴다.
- 상위 단계를 건너뛰지 않고 순서대로 사용한다.
